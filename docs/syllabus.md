# 课程大纲

> 总学时建议：48 学时（理论 24 + 实践 24）

## 课程目标

学完本课程后，**你能够**：

1. **理解** 编译器前端（词法/语法/语义）、中端（IR/优化）、后端（目标代码）每一层的核心问题与主流解法。
2. **比较** 不同技术路线（手写 vs 工具生成、LL vs LR、SSA vs 三地址码、单遍 vs 多遍），并能说出现场为何这么选。
3. **动手** 用 `flex`/`bison` + LLVM 实现一个能跑真实程序的 C1 子集编译器。
4. **入门** Clang/LLVM 生态：阅读 AST、写一个 Pass 或 Plugin。

## 评价方式

| 项目 | 占比 | 说明 |
| ---- | ---- | ---- |
| 平时作业（每章小练） | 30% | 10 次左右，提交代码+截图 |
| 期中（实现一个表达式计算器/玩具语言） | 25% | 第 6 章后验收 |
| 期末项目 | 45% | 综合：扩展 C1 或写一个 Clang 工具 |

## 推荐先修

- C/C++ 基础（指针、结构体、虚函数、模板）
- 数据结构（树、图、栈）
- 计算机组成原理基础（栈帧、寄存器、调用约定）
- 一点形式语言/离散数学基础

## 推荐参考书

- Aho/Lam/Sethi/Ullman《编译原理》（龙书）—— 理论权威
- Appel《现代编译原理：C 语言描述》（虎书）—— 与 LLVM 思路接近
- Louden《编译原理及实践》—— 教材级
- Levine/Mason/Brown《Lex 与 Yacc 第二版》—— 工具书
- LLVM Developer Reference —— 查 LLVM API
