# 附录 B：LR(0) 详细推演

> 本文用参考 HTML 中的例子一步步推演 LR(0) 项目集族，便于理解第 5 章的概念。
> 原文：[`ref-html-zh.md` §11.2](../reference/ref-html-zh.md#112-构造-lr0-分析器)

## B.1 语法

```
S -> A
A -> aBd
B -> bc
```

## B.2 起始状态 I0

```
I0 = CLOSURE({ [S -> •A] })
```

闭合：因为 `S -> •A` 黑点后是非终结符 `A`，所以 `A` 的所有产生式的起始形态要加入：

```
I0 = {
    [S -> •A],
    [A -> •aBd]      ← A 的产生式起始形态
}
```

## B.3 求 I0 的所有后继状态

对每个符号 `X ∈ {S, A, B, a, b, c, d}`，求 `NEXT(I0, X)`：

### NEXT(I0, A)

`[S -> •A]` 遇到 `A`，黑点后移到 `A` 后面：

```
{[S -> A•]}
```

闭包后无新形态：

```
I1 = { [S -> A•] }   ← 可折叠形态（completed）
```

### NEXT(I0, a)

`[A -> •aBd]` 遇到 `a`，黑点移到 `a` 后面：

```
{[A -> a•Bd]}
```

闭包：因为 `Bd` 中 `B` 是非终结符，所以 `B` 的所有起始形态要加入：

```
I2 = {
    [A -> a•Bd],
    [B -> •bc]       ← B 的产生式起始形态
}
```

### 其他符号

`NEXT(I0, S)`, `NEXT(I0, B)`, `NEXT(I0, b)`, `NEXT(I0, c)`, `NEXT(I0, d)` 都是空集。

## B.4 继续求后继

### NEXT(I2, B)

`[A -> a•Bd]` 遇到 `B`：

```
{[A -> aB•d]}
```

闭包后：

```
I3 = { [A -> aB•d] }
```

### NEXT(I2, b)

`[B -> •bc]` 遇到 `b`：

```
{[B -> b•c]}
```

闭包后：

```
I4 = { [B -> b•c] }
```

### NEXT(I3, d)

`[A -> aB•d]` 遇到 `d`：

```
{[A -> aBd•]}
```

闭包后：

```
I5 = { [A -> aBd•] }   ← 可折叠
```

### NEXT(I4, c)

`[B -> b•c]` 遇到 `c`：

```
{[B -> bc•]}
```

闭包后：

```
I6 = { [B -> bc•] }    ← 可折叠
```

### 其他符号

`NEXT(I1, *)`、`NEXT(I3, *)`（除 d）、`NEXT(I4, *)`（除 c）、`NEXT(I5, *)`、`NEXT(I6, *)` 全部为空集（因为状态里的形态黑点后要么是终结符后没东西，要么就没有下一个符号能接上）。

## B.5 完整状态转移图

```
                  A              a
            ┌──────────┐    ┌──────────┐
            ▼          │    ▼          │
   ┌────►  I1         │    I2 ── B ──► I3 ── d ──► I5
   │        │         │    │                  │
   │        │         │    │                  b
   │        │         │    │                  ▼
I0─┤        │         │    │                 I4 ── c ──► I6
   │        │         │    │
   │        │         │    └─► ...
   └────────┘
   (其他符号无转移)
```

ASCII 版本：

```
                A                  a
            ┌──────┐          ┌──────┐
            │      │          │      │ B          d
            ▼      │          ▼      ▼
   ┌────► I1     I0    ───►  I2  ─────► I3 ─────► I5
   │                                      
   │                          b          c
   │                          ▼          ▼
   └─►...                     I4 ─────► I6
```

## B.6 LR(0) 分析表

空白表示 deny（输入不合语法）。

| 状态 | A | B | a | b | c | d | $ |
| ---- | - | - | - | - | - | - | - |
| I0   | goto I1 |  | shift I2 |  |  |  |  |
| I1   |  |  |  |  |  |  | **ACCEPT** |
| I2   |  | goto I3 |  | shift I4 |  |  |  |
| I3   |  |  |  |  |  | shift I5 |  |
| I4   |  |  |  |  | shift I6 |  |  |
| I5   | reduce A→aBd |  |  |  |  |  |  |
| I6   | reduce B→bc |  |  |  |  |  |  |

## B.7 用分析表跟踪 abcd

| Sym-Stack | State-Stack | 当前 X | Remaining | Parse Action |
| --------- | ----------- | ------ | --------- | ------------ |
|           | I0          | a      | abcd$     | M[I0,a] = shift I2 |
| a         | I0 I2       | b      | bcd$      | M[I2,b] = shift I4 |
| ab        | I0 I2 I4    | c      | cd$       | M[I4,c] = shift I6 |
| abc       | I0 I2 I4 I6 | d      | d$        | M[I6,d] = reduce B→bc |
| a         | I0 I2       | B      | d$        | M[I2,B] = goto I3 |
| aB        | I0 I2 I3    | d      | d$        | M[I3,d] = shift I5 |
| aBd       | I0 I2 I3 I5 | $      | $         | M[I5,$] = reduce A→aBd |
|           | I0          | A      | $         | M[I0,A] = goto I1 |
| A         | I0 I1       | $      | $         | M[I1,$] = **ACCEPT** |

## B.8 总结

7 个状态、12 个表项填了动作、其余都是 deny。
这个语法"刚好"是 LR(0) 语法，因为：
- I1、I5、I6 都是只有一个可折叠形态的状态
- 其他状态都不含可折叠形态

如果加入 `A -> aBe | aBf` 这种选择，就会引入 shift/reduce 冲突，破坏 LR(0) 性质。

## B.9 自己练一练

试着用上面的方法分析下面这个简单语法：

```
S -> a | aS
```

要求：
1. 加 `S' -> S` 把 S 从右边拿出来
2. 写出 I0
3. 写出所有后继状态
4. 构造分析表
5. 跟踪 `aaa`

提示：你会遇到 shift/reduce 冲突（这个文法不能用 LR(0) 分析）。
